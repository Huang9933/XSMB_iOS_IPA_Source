Kiểm Thử Lịch Sử (Walk-Forward Backtesting)

Giả lập tại mỗi ngày $t$, mô hình chỉ dùng các ngày trước đó ($t-1, t-2, \dots$) để dự đoán và đối chiếu với kết quả thực tế

Ngày mở thưởng Giải ĐB thực tế Đề về Top 3 Chạm Đầu/Đuôi dự đoán Top 3 Tổng dự đoán Xếp hạng số thực tế Kết quả kiểm thử

Nhập / Dán Kết Quả Mới Từ soketqua.vn

Có 2 cách nhập. Mỗi lần thêm kỳ, mọi tab (Dự đoán, Thống kê, Siêu cầu cộng tổng, Cầu vị trí, Phôi ĐB) được dò lại và vẽ lại theo dữ liệu mới. Dữ liệu bạn nhập được lưu ngay trong trình duyệt này, mở lại vẫn còn.

Dán nhiều ngày một lúc cũng được (cũ → mới hay mới → cũ đều tự xếp đúng thứ tự). Phải đủ cả 27 giải thì cầu vị trí và cầu cộng tổng mới cập nhật; chỉ có ĐB/G1/G7 thì Dự đoán, Thống kê và Phôi ĐB vẫn cập nhật.

Ngày mặc định là kỳ kế tiếp sau kỳ mới nhất. Bỏ trống Giải 2–6 nếu chỉ có ĐB, G1, G7 (khi đó các tab cầu vị trí / cộng tổng chưa cập nhật).

Kiến Trúc Dự Án Python (`scraper.py` + `predictor.py`)

Mã nguồn đầy đủ đã được đóng gói trong file xsmb_predictor_project.zip để bạn chạy trực tiếp trên máy cá nhân hoặc server

# Chạy dự án trên máy cá nhân:
# 1. Giải nén xsmb_predictor_project.zip
# 2. Cài đặt thư viện: pip install -r requirements.txt
# 3. Chạy dự đoán: python3 predictor.py

from scraper import fetch_from_soketqua
from predictor import XSMBPredictor

# Tự động tải KQXS mới nhất từ https://soketqua.vn/
history = fetch_from_soketqua(live=True)
model = XSMBPredictor(history)
result = model.predict(w_freq=0.30, w_markov=0.30, w_bridge=0.25, w_gap=0.15)

print("Top 10 Bạch Thủ Đề:", result["top_10"])
print("Dàn Đề 20 số:", result["dan_20"])
